# Tery-Emballage

Gros emballages PP (vêtements usagés) — boutique en ligne Flask + SQLite.

## Produits

- Sac PP tissé blanc (80×125, 132 g) — construction, non laminé
- Sac PP tissé transparent (80×115, 108 g) — chaussures, non laminé
- Feuille PP transparente (105×135, 95 g) — balles de vêtements, laminée

Quantité minimale : 2000 pièces. Tarifs dégressifs par paliers, négociation dès 10 000 pièces.

## Lancement local

```bash
pip install -r requirements.txt
python3 start.py
```

Serveur sur http://127.0.0.1:8791 (admin : `/admin`).

## Stack

Flask · SQLite · templates Jinja · CSS/JS vanilla (carrousels, panier AJAX).
